# 🌻 Flores Amarillas — Jardín Digital

Una experiencia web interactiva y kawaii creada como una forma digital de regalar flores amarillas. 💛

## ✨ Sobre el proyecto

La página muestra un pequeño jardín nocturno con flores amarillas de estilo **caricaturesco y kawaii**.

Al tocar la pantalla, aparecen nuevas flores que crecen desde el suelo acompañadas de pequeños efectos de luz. La experiencia está diseñada para funcionar tanto en móviles como en ordenadores y puede compartirse fácilmente mediante un enlace.

## 🌻 Características

- 🌻 Flores amarillas animadas.
- 🎨 Diseño caricaturesco / kawaii.
- 🌙 Fondo nocturno.
- ⭐ Estrellas con animación.
- 🌕 Luna decorativa.
- 🌱 Flores que brotan desde el suelo.
- 👆 Interacción táctil y con ratón.
- ✨ Efectos de partículas al tocar.
- 💛 Mensaje especial después de varias interacciones.
- 📱 Diseño responsive.
- 🚫 Una sola pantalla, sin scroll.
- ⚡ Sin librerías externas.

## 💬 Mensaje

Después de varias interacciones aparece:

> **🌻 Para ti 💛**  
> Que nunca te falten motivos para florecer.

El mensaje puede modificarse directamente en `index.html`.

## 🎯 Objetivo

Crear una alternativa digital a las tradicionales flores amarillas: una pequeña experiencia interactiva, bonita y fácil de compartir.

💛 **Una flor puede ser física. Una experiencia puede quedarse en la pantalla.** 🌻
